# Security policy

This repository contains read-only research and deterministic demonstrations. No private signing keys, recovery phrases, service credentials, protected internal logs, or customer data belong here.

If you discover a security issue, **do not publish an exploit containing secrets or private infrastructure details in a public issue**. [GitHub private vulnerability reporting](https://github.com/Footloose9/hyperfabric-evolution/security/advisories/new) is enabled for this repository; use it for sensitive disclosures, or notify the repository owner through an established private communication channel. Do not create wallet transactions to prove a vulnerability.

The published synthetic code is not a wallet, signer, trading engine, investment product, or security assurance system and makes no live ledger calls. The separate, opt-in XRPL read-only viewer does contact a third-party public provider; the provider may observe visitors' IP addresses and the public account addresses they query. No deployed secure messaging, privacy network, cryptographic key custody or production security certification is claimed.
