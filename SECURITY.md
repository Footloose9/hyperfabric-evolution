# Security policy

This repository contains read-only research and deterministic demonstrations. No private signing keys, recovery phrases, service credentials, protected internal logs, or customer data belong here.

If you discover a security issue, **do not publish an exploit containing secrets or private infrastructure details in a public issue**. Use GitHub's private vulnerability reporting mechanism when available, or notify the repository owner through an established private communication channel. Do not create wallet transactions to prove a vulnerability.

The sample code is not a wallet, signer, trading engine, investment product, or security assurance system. It makes no live network calls.
